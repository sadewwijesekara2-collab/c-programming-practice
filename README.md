## How to Run

You need a C compiler such as GCC.

For example, open a terminal in the folder containing a `.c` file and run:

```bash
gcc filename.c -o program
```

Then run the compiled program:

**Windows**
```bash
program.exe
```

**Linux / macOS**
```bash
./program
```

Replace `filename.c` with the name of the C source file you want to compile.
